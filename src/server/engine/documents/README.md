# Yessyfy documents — Brand 0.0.1

The vendored `brand/src` is the actual source from `brand-20261011_130845.txt`, retaining the MIT license and native named `load-render()` / `render-job` facade. Recipes own Yessyfy's data schema and literal business content; they do not duplicate Brand's layout engine. Bundled DejaVu fonts retain their license.

`brands.json` owns identity and typed tokens. The compiler uses the fixed report/warranty/invoice allowlist, an isolated root, manifest-verified bytes, pinned fonts, no system fonts, no inherited environment, a seven-second compiler deadline and a 20 MB PDF cap. Metadata and exact MXN strings come from server snapshots. Up to six authorized evidence images are staged under logical asset IDs; no image URL is fetched by Typst.

The bundle manifest records schema `brand.render/1`, Brand version `0.0.1` and the SHA-256 of each runtime file. Rebuild the manifest after approved edits and keep the prior bundle for rollback. A source/manifest mismatch refuses startup.

Generated development PDFs carry a development/fiscal-invalidity watermark. The integration suite validates real PDF bytes for all three recipes. Actual provider stamping is separately accepted through the signed fiscal adapter.
