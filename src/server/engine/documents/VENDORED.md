# Brand and font provenance

Brand package: 0.0.1; compiler baseline: Typst 0.15.0.

Source: the user-owned `brand-20261011_130845.txt` source export. Every vendored `.typ` file under `brand/src` matches the corresponding extracted upstream text. No compatibility facade or upstream implementation changes were applied. The original MIT license is retained.

DejaVu Sans/Mono/Serif font files were reconstructed from the installed DejaVu distribution because the source export represented binary files as placeholders. The actual font bytes and license are packaged and bound by the bundle manifest. Document rendering is verified against these packaged bytes.

Yessyfy recipes and identity are consumer-owned additions. The default labels and warranty text are configuration examples; approved production wording remains a deployment acceptance item.
